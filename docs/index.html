One pipeline around the Android toolchain.

ANBE is not a replacement for Gradle. It is the orchestration, diagnostics, compatibility and release layer around it.

Build intelligence

Project discovery, structured recipes, product-flavor detection, dependency-aware planning and deterministic execution.

Termux compatibility

JDK selection, Gradle wiring, ARM64 AAPT2 override, protobuf fallback and Android-specific compatibility repair.

Release engineering

Debug APK, signed release APK, AAB, artifact verification, SHA-256, signature checks, reports and export.

Self-healing repairs

Narrowly scoped and idempotent fixes for AndroidX, launcher icons, Gradle wrappers, native dependencies and more.

Product flavors

Variant-aware task generation such as assembleDemoDebug and correct flavored artifact discovery.

Long-build visibility

Progress reporting and heartbeat output make it obvious that large on-device builds are still alive.
